## JSPとURLのリクエストパス

まずはWebアプリケーションの開発イメージが沸きやすいように画面まわりから作成していく。

Webアプリケーションの画面（HTML）を作成する際は、JSPを作成する。

JSPはHTMLコードの中にJavaプログラムを埋め込み、Webサーバ上で動的にWebページ（HTML）を生成・表示する仕組みです。
